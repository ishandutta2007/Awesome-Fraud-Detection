# 🚀 Awesome-Fraud-Detection

**Curated List of SaaS Products & Open-Source GitHub Projects**  
*Focused on Transaction Fraud, Account Abuse, Chargeback Prevention, Device Intelligence & Real-Time Risk Scoring*  
**Last updated: August 2026**

</div>

This repository tracks notable **SaaS platforms** and **open-source projects** for **Fraud Detection**, Risk Management, and Cybersecurity. These tools analyze transactions, devices, behavior, and identity signals in real time to score risk, block fraudulent activity, reduce chargebacks, detect account takeovers, and support investigation workflows across e-commerce, payments, fintech, and digital platforms.

## 🏢 SaaS/Hosted Platforms

| Platform | Description | Pricing | Free Tier Limit | Company Size |
|----------|-------------|---------|-----------------|--------------|
| **[Forter](https://www.forter.com/)** | Identity-based fraud decisioning platform that provides real-time approve/decline decisions using a large cross-merchant identity graph. | Custom | None | $3B Valuation |
| **[Feedzai](https://www.feedzai.com/)** | Enterprise RiskOps platform for banks and payment processors combining fraud, AML, and real-time transaction monitoring with explainable AI. | Custom / Enterprise | None | $1.5B Valuation |

| **[Kount (Equifax)](https://kount.com/)** | Identity-trust and fraud scoring solution with configurable rules, device data, and global identity insights for e-commerce and payments. | Custom / Enterprise | None | $640M Acquired |

## 💻 Open-Source GitHub Projects

- **[FingerprintJS](https://github.com/fingerprintjs/fingerprintjs)** [![Stars](https://img.shields.io/github/stars/fingerprintjs/fingerprintjs?style=social&color=white)](https://github.com/fingerprintjs/fingerprintjs/stargazers)  
  Open-source browser and device fingerprinting libraries that can feed custom fraud and bot-detection pipelines.

- **[PyOD](https://github.com/yzhao062/pyod)** [![Stars](https://img.shields.io/github/stars/yzhao062/pyod?style=social&color=white)](https://github.com/yzhao062/pyod/stargazers)  
  Comprehensive Python library for anomaly/outlier detection with 60+ algorithms across tabular, time-series, graph, and other data modalities.

- **[Orion](https://github.com/sintel-dev/Orion)** [![Stars](https://img.shields.io/github/stars/sintel-dev/Orion?style=social&color=white)](https://github.com/sintel-dev/Orion/stargazers)  
  MIT-originated open-source time-series anomaly detection framework designed for accessibility and large-scale industrial use.

- **[PyGOD](https://github.com/pygod-team/pygod)** [![Stars](https://img.shields.io/github/stars/pygod-team/pygod?style=social&color=white)](https://github.com/pygod-team/pygod/stargazers)  
  Python library specialized in graph outlier detection using modern graph neural network techniques.

- **[DGFraud](https://github.com/safe-graph/DGFraud)** [![Stars](https://img.shields.io/github/stars/safe-graph/DGFraud?style=social&color=white)](https://github.com/safe-graph/DGFraud/stargazers)  
  Deep graph-based toolbox implementing state-of-the-art GNN models for fraud detection on heterogeneous and homogeneous graphs.

- **[AWS Fraud Detection](https://github.com/awslabs/fraud-detection-using-machine-learning)** [![Stars](https://img.shields.io/github/stars/awslabs/fraud-detection-using-machine-learning?style=social&color=white)](https://github.com/awslabs/fraud-detection-using-machine-learning/stargazers)  
  AWS reference architecture and ML pipelines for detecting fraud.

- **[UGFraud](https://github.com/safe-graph/UGFraud)** [![Stars](https://img.shields.io/github/stars/safe-graph/UGFraud?style=social&color=white)](https://github.com/safe-graph/UGFraud/stargazers)  
  Unsupervised graph-based toolbox for fraud detection complementary to supervised GNN approaches.

- **[AntiFraud (AI4Risk)](https://github.com/finint/antifraud)** [![Stars](https://img.shields.io/github/stars/finint/antifraud?style=social&color=white)](https://github.com/finint/antifraud/stargazers)  
  Collection of published graph and deep-learning models for credit-card and financial fraud detection.

- **[Transaction Anomaly Detection](https://github.com/KuchikiRenji/Transaction-Anomaly-Detection)** [![Stars](https://img.shields.io/github/stars/KuchikiRenji/Transaction-Anomaly-Detection?style=social&color=white)](https://github.com/KuchikiRenji/Transaction-Anomaly-Detection/stargazers)  
  Enterprise-style fraud & AML system with XGBoost/LightGBM, autoencoders, LSTM/Transformer models.

- **[Rift](https://github.com/AngelP17/Rift)** [![Stars](https://img.shields.io/github/stars/AngelP17/Rift?style=social&color=white)](https://github.com/AngelP17/Rift/stargazers)  
  Graph-based intelligence system for entity resolution, anomaly detection, and investigative workflows.

- **[Jube](https://github.com/jube-home/aml-fraud-transaction-monitoring)** [![Stars](https://img.shields.io/github/stars/jube-home/aml-fraud-transaction-monitoring?style=social&color=white)](https://github.com/jube-home/aml-fraud-transaction-monitoring/stargazers)  
  Full open-source AML and fraud transaction monitoring platform with real-time scoring (AGPLv3).

- **[Fraud Detection MCP](https://github.com/marc-shade/fraud-detection-mcp)** [![Stars](https://img.shields.io/github/stars/marc-shade/fraud-detection-mcp?style=social&color=white)](https://github.com/marc-shade/fraud-detection-mcp/stargazers)  
  Model Context Protocol server combining Isolation Forest, autoencoders, behavioral biometrics.

- **[tirreno](https://github.com/tirreno/tirreno)** [![Stars](https://img.shields.io/github/stars/tirreno/tirreno?style=social&color=white)](https://github.com/tirreno/tirreno/stargazers)  
  Security framework focused on event tracking, threat detection, and risk scoring for applications.

## 🤝 How to Contribute

1. Fork the repo.
2. Add/edit entries in `README.md` (follow existing format).
3. Include: name, link, 1–2 sentence description, and whether it's SaaS or open-source.
4. Submit PR with a short explanation.

Star the repo if you find it useful! ⭐

## ⚠️ Disclaimer

- This is a **community-curated** list — not exhaustive and not an endorsement.
- Fraud detection systems must comply with applicable regulations (PCI-DSS, GDPR, AML/KYC requirements, etc.) and ethical data-use policies.
- Self-hosted open-source solutions require careful model governance, bias monitoring, data security, and operational reliability.
